# 使い方・時刻の読み方

[← ドキュメント一覧（README）](../README.md)

このページでは、NITOCバスナビの時刻表示を間違えずに読むために必要な点だけを説明します。

## 1. 行き・帰りを選ぶ

| 方向 | 表示される主な時刻 | ページ |
| --- | --- | --- |
| **小山駅東口 → 小山高専** | **小山駅東口をバスが発車する時刻** | [行き](https://nitocbus.pages.dev/obus_2026_kosen_s2k) |
| **小山高専 → 小山駅東口** | **高専正門を徒歩で出発する目安時刻** | [帰り](https://nitocbus.pages.dev/obus_2026_kosen_k2s) |

行きは、駅からバスに乗るための時刻を表示します。帰りは、学校から停留所へ歩く時間を含めて考えられるように、**正門出発の目安**を表示します。両者は同じ意味の時刻ではありません。

## 2. 帰りの「正門出発目安」とは

帰りの表示は、公式時刻表の停留所発車時刻から、あらかじめ設定した徒歩時間を差し引いています。

| バスに乗る停留所 | 正門からの徒歩補正 | 表示時刻の計算 |
| --- | ---: | --- |
| 高専正門 | 0分 | 公式時刻 − 0分 |
| 小山高専入口 | 6分 | 公式時刻 − 6分 |
| 中久喜二丁目 | 9分 | 公式時刻 − 9分 |

例えば、**小山高専入口を17:30に発車する便**なら、正門出発目安は**17:24**と表示する計算です（これは説明用の例で、実在する便の時刻を示すものではありません）。

> [!CAUTION]
> 正門出発目安は**参考値**です。徒歩の速さ、信号、のりばの位置などで必要時間は変わります。表示時刻を実際のバス発車時刻と取り違えないようにしてください。

## 3. 路線・停留所を確認する

| 路線 | 高専側で使う主な停留所 |
| --- | --- |
| **3 高岳線** | 小山高専入口 |
| **4 城東中久喜線** | 高専正門 |
| **16 桑東部絹路線** | 便によって高専正門または中久喜二丁目 |

桑東部絹路線は**便ごとに停留所を確認**してください。表示にある「正門」「入口」「中二」は、それぞれ上表の停留所の略称です。

## 4. 運行日記号を確認する

時刻表に表示される記号は、運行日の条件を示します。

| 記号 | データ上の運行条件 |
| --- | --- |
| 記号なし | 曜日制限なしの設定（臨時運休などは別） |
| **※** | **平日（月～金）のみ**。祝日は運休 |
| **◆** | **月～金に運行**。祝日でも運行しますが、土日と12月29日～1月3日は運休 |

◆と※は同じ条件ではありません。特に**祝日の扱い**が異なります。最新の運行条件や臨時運休は[小山市公式情報](https://www.city.oyama.tochigi.jp/o-bus/rosen-jikoku/page001803.html)で確認してください。

## 5. 発車標・時計用画面・PDF

- **[発車標](https://nitocbus.pages.dev/departure/)**：現在時刻と、時刻表に基づくこの先の便を表示します。高専から駅方面は[帰り用](https://nitocbus.pages.dev/departure/k2s/)へ。
- **[時計用画面](https://nitocbus.pages.dev/watch/)**：小画面向けの簡略版です。方向を切り替えられ、次の3便を扱います。Galaxy Watchなどでは対応ブラウザから利用します。
- **PDF版**：トップページの方向別リンクから開けます。印刷・保存向けのA4縦版です。

発車標・時計用画面は、端末内で現在時刻と時刻表を照らし合わせています。**GPSで車両を追跡するリアルタイム運行情報ではありません**。長時間開いたままにした画面は、新しい時刻表データを読み込むために再読み込みしてください。

## 6. 迷ったときの確認先

**時刻表の改正、臨時運休、路線全体の時刻、運賃**については、必ず[小山市公式の路線・時刻表](https://www.city.oyama.tochigi.jp/o-bus/rosen-jikoku/page001803.html)を優先してください。

NITOCバスナビは**2026年10月1日改正に対応した非公式・個人制作サイト**であり、小山市や運行事業者の公式案内ではありません。
